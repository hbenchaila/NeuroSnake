# 1. Goal:
A Deep Q-Learning Snake agent, with the neural network written from scratch in NumPy,
verified against PyTorch, and evaluated honestly.

# 2. Scope:
Level 1 mandatory. Level 2 with the ablation first. Level 3 deferred.

# 3. Functional requirements:
Standalone environement, 11-feature encoder, NumPy network with manual backprop, DQN with replay and target network, PyTorch twin, evaluation script, Streamlit dashboard.

# 4. Non-functional:
CPU only, every run reproducible from config and seed, tests executed before any claim, no invented numbers.

# 5. Success:
the 12-point Definition of Done. A high score is not a gate.

# 6. Out of scope:
GPU or cloud, CNN state, multi-agent.
